# Billing Guide

This guide explains how billing works for the Serika.dev Customer API, including pricing, usage calculation, and account management.

## Billing Models

The Serika.dev Customer API offers two types of accounts:

1. **Free Accounts**: Limited access to models and features with usage caps
2. **Accounts with Billing**: Full access to all models and features with usage-based billing

## Setting Up Billing

To set up billing for your API usage:

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "Billing"
4. Click "Set Up Billing"
5. Follow the prompts to enter your payment information
6. Once billing is set up, your API keys will automatically have access to premium features

## Usage Metering

### Text Generation

Text generation is metered based on the number of tokens used. A token is approximately 4 characters or 0.75 words in English.

Usage is calculated as the sum of:
- Input tokens (the messages you send in your request)
- Output tokens (the completions generated by the API)

For example, if you send a request with 10 tokens and receive a response with 20 tokens, your usage for that request would be 30 tokens.

### Image Generation

Image generation is billed at a fixed rate per image, regardless of prompt length. In token terms, each image is equivalent to approximately 1000 tokens.

## Viewing Your Usage

To view your API usage:

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "API Usage"
4. You can view usage statistics by:
   - Time period (daily, weekly, monthly)
   - API key
   - Endpoint

## Pricing

Current pricing for the Serika.dev Customer API is as follows:

### Free Tier

- Access to `euryale-70b` and `mistral-7b` models
- Limited to 200,000 tokens per month for text generation
- Limited to 20 image generations per month
- Maximum of 200 tokens per response
- Rate limited to 20 requests per minute

### Premium Tier

- Full access to all models, including premium models like `claude-3-opus` and `mixtral-8x7b`
- Increased token limits (up to 2000 tokens per response)
- Text generation: $0.002 per 1K tokens (approximately $0.000002 per token)
- Image generation: $0.02 per image
- Higher rate limits (200 requests per minute)

### Premium Models Pricing

Premium models (available only with billing set up) have the following pricing:

| Model | Input Price (per 1K tokens) | Output Price (per 1K tokens) |
|-------|----------------------------|------------------------------|
| `euryale-70b-premium` | $0.0015 | $0.002 |
| `mixtral-8x7b` | $0.01 | $0.02 |
| `gemma-7b` | $0.008 | $0.015 |
| `claude-3-opus` | $0.03 | $0.06 |
| `novelai/nai-diffusion-3` | - | $0.02 per image |

## Payment and Billing Cycles

- Billing is handled through Stripe
- You are billed monthly for your actual usage
- Invoices are generated on the 1st of each month for the previous month's usage
- You can view your invoice history in the Developer section under "Billing"

## Managing Your Billing

### Viewing Invoices

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "Billing"
4. Click "Invoices" to view your billing history

### Updating Payment Method

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "Billing"
4. Click "Payment Methods"
5. Follow the prompts to add or update your payment information

### Setting Usage Limits

To avoid unexpected charges, you can set usage limits:

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "Billing"
4. Click "Usage Limits"
5. Set your desired monthly usage limit
6. When your usage approaches or reaches this limit, you'll receive notifications

## Cancellation

To cancel your billing subscription:

1. Log in to your Serika.dev account
2. Navigate to the Developer section
3. Click on "Billing"
4. Click "Cancel Subscription"
5. Confirm the cancellation

After cancellation:
- Your account will revert to the free tier at the end of the current billing period
- You will still have access to the API with free tier limitations
- Your existing API keys will continue to work but will be limited to free models

## Frequently Asked Questions

### How is token usage calculated?

Token usage is calculated based on both input and output tokens. Different models may count tokens slightly differently, but as a general rule, 1 token is approximately 4 characters or 0.75 words in English.

### Will I be charged if my API request fails?

No, you will only be charged for successful API requests. If a request fails due to an error, you will not be charged for that request.

### Can I set a spending limit?

Yes, you can set a monthly spending limit in the Billing section. When you reach this limit, API requests will be rejected until the next billing cycle or until you increase your limit.

### What happens if I exceed my free tier limits?

If you exceed your free tier limits, API requests will be rejected with a 429 (Rate Limit Exceeded) error until the next billing cycle or until you set up billing.

### Do unused free tier tokens roll over to the next month?

No, unused free tier tokens do not roll over. The free tier allocation resets at the beginning of each month.
